# 详情卡加载稳定性与入场修复

状态：实现与 root 技术验收完成，待用户体验验收；基线 c05d550，沿用 feat/dynamic-bookshelf。用户验收前不推送、合并或部署。本需求替代 centered-detail.md 中自适应内容高度与 240ms 上移动画的约定。结果见 [验收记录](detail-stability-acceptance.md)。

## 已复现的问题

详情先显示简短占位，异步缓存返回后替换为完整内容。卡片按内容确定高度，再用自身高度的 -50% 垂直居中。1920×963 浏览器中，卡片高度从约 516px 增至 604px，顶部从约 223px 上移至 180px；页面滚动与焦点未变。现有动画前 60ms 已完成约 72%，使出现偏急，随后异步重排又产生第二次位移。

## 用户可见结果

点击后，固定大小的暖白卡片平缓出现。简介、推荐值、进度和笔记返回时，外框、封面、标题与关闭按钮的位置保持稳定。长内容仅在卡片内部滚动。支持缓存命中、首次加载、刷新、失败与重试；开闭和焦点恢复保持可用。

## 实现约束

- 桌面外框宽 850px（保留左右至少 32px），高 min(620px, 100dvh - 64px)；手机宽 calc(100vw - 32px)，高 min(660px, 100dvh - 40px)。本次显示期间不根据数据重算高度；视口变化时允许响应式调整。接受短内容适度留白。
- 居中定位与动画分开：外层布局负责居中，卡片只执行 opacity 与 scale。移除动画中所有 translate；避免定位和动效争用同一 transform。保持原生 dialog，不引入新依赖。
- 打开约 300ms，opacity 0→1，scale .99→1，使用平缓的 ease-in-out；遮罩约 220ms 同步淡入。关闭约 180ms，opacity 1→0、scale 1→.995，无位移；遮罩一起关闭。最终时长可由 root 视觉复核小幅调整。
- 动画开始前初始状态可确定；关闭取消入场，重开取消旧关闭和遮罩动画。旧完成回调不能影响新详情；已完成动画不能残留 fill 效果。reduced motion 仅短淡入淡出；无 WAAPI 仍可用。
- 固定详情分区先显示具有阅读含义的占位（简介若干行或固定占位区域，推荐值/笔记明确加载中），不能把未返回数据呈现为确定的“暂无”或零；无闪烁扫光。内容更新不重播整卡动画。
- 可使用按书籍 id 的会话内详情缓存，让同本重开第一帧显示已有内容；不新增持久缓存、API 或请求。成功书架快照替换时清空该缓存，避免更换账号后旧数据继续使用。详情与笔记的有效返回更新此缓存；分区失败保留既有内容，token 隔离仍有效。
- 外框固定后，内容区域必须明确约束高度；桌面长正文、手机长标题/长正文、矮屏均不能裁掉可操作内容。关闭按钮始终可见，背景不滚动；打开聚焦使用 preventScroll。
- 不修改后端、统计、筛选、同步协议或依赖。

## 分工与验收

root 提需求、审查并最终视觉验收；gpt-6-luna 开发仅改 web，独立 gpt-6-luna 测试 agent 改 tests 及必要 CI。agent 均不提交，由 root 完成最终提交。

自动化保留原检查，更新入场/关闭契约；覆盖数据返回不重播、会话缓存首帧及失效、部分失败回退、旧返回隔离、取消与无 WAAPI。用红绿或变异检查证明关键断言有效。

测试 agent 提供可复用的本地演示诊断服务（仅标准库，不在生产应用新增调试路由），支持缓存 GET 与后台更新分别延迟、长正文、冷/热状态；在真实浏览器按帧采样外框无变换尺寸、中心、关闭按钮和 scrollY，把结果写入诊断页的 DOM 供只读检查。可选慢放只用于视觉检查，不影响产品动画参数。测试服务只使用虚构数据。

root 必须在真实 Chrome 做视觉确认：1920×963、390×844、1000×540、390×560；检查加载占位→缓存返回→更新返回全程，并在正常速度和慢放下查看入场前/中/结束画面。0ms、300ms、1500ms 延迟下外框布局尺寸不变，中心不漂移（正常 scale 的边缘变化不算布局跳动），标题与关闭按钮稳定。实际滚动长内容，验证按钮/遮罩/Esc、焦点与滚动返回、失败重试。保存虚构演示截图或阶段图，记录测量证据及限制，不能只据最终截图宣称中间态通过。
