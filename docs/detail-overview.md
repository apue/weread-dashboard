# 书籍详情概览与渐进展开

日期：2026-11-16。基线 144aead，分支 feat/dynamic-bookshelf。用户同意试一版，体验验收前不推送或合并。root 设计与最终视觉验收，gpt-6-luna 开发与独立测试。开发与技术验收已完成，[结果与截图](detail-overview-acceptance.md)，等待用户体验验收。

## 用户可见结果

详情从书架的选中反馈衔接到轻柔居中浮现。默认呈现一眼可读的完整概览，桌面不需要滚动；用户展开长简介后，正文自然推下其他内容，超出可用高度才滚动。保留页面滚动条槽、异步加载稳定性和当前数据缓存逻辑。

## 布局

- 面板约 820–840px 宽，桌面固定约 580–600px 高并受视口高度约束；手机宽为视口减 32px，高不超过视口减 40px。固定的是外框，数据返回不改变中心或高度。短屏允许内部滚动。
- 上方身份区：较小封面（桌面约 108×154px，手机约 76×108px）、书名、作者、类型、出版信息与阅读进度。长书名最多三行，保留完整可访问名称；身份区预留稳定高度。缺封面、元数据仍可读。
- 简介改为全宽，默认最多四行；内容短时不出现按钮。仅实际溢出时提供“查看更多”，展开为完整段落，按钮变为“收起”，aria-expanded 与 aria-controls 正确。收起时不丢失按钮焦点，不让页面或面板跳走。
- 推荐值与划线、想法/点评、书签数量紧凑横排，保留各字段独立含义、未知状态与评价人数。笔记同步作为紧凑底部操作；保留错误、重试、阅读链接、文章和有声书入口说明。
- 只保留一个详情内部滚动容器，overflow:auto，不隐藏必要滚动条。默认桌面概览完整显示；展开内容正常挤下后续区块。手机不横向溢出。展开造成垂直滚动条出现时预留空间，避免正文横移。
- 展开为本地 UI 操作，不发请求；异步 cached/fresh 返回及笔记同步不能自动折叠当前书籍。切换或重新打开书籍默认收起，旧请求不能改变新书展开状态。超长英文、换行与 HTML 字符安全处理。

## 动效

选中书卡先有短促轻微反馈；背景淡入先开始，卡片稍后进入（约 30–40ms），以淡入和 .985→1 的微缩放为主，约 300–320ms。面板位置无 translate。次要详情内容再稍晚几十毫秒淡入，不逐项飞入，不在数据刷新时重播。关闭约 160–180ms，并取消所有未完成入场动画；快速关闭重开不能被旧 completion 关闭。reduced-motion 仅短淡入且无额外等待，无 WAAPI 时也能正常开闭。

## 验证与分工

开发 agent 仅修改 web；独立测试 agent 修改 tests，针对展开判定、状态保持/重置、无额外请求和动画取消先补检查，再验证实现。root 审查最终 diff，运行仓库要求的 Python 与前端检查，亲自在 Chrome 验证：正常速度与慢放、长简介折叠→展开→收起、短简介无按钮、异步加载外框稳定、桌面概览无滚动、手机与短屏可达、16px 页面滚动条下无横移、Esc/按钮/遮罩关闭与焦点恢复。截图与采样只用虚构数据。
