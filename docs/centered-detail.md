# 居中书籍详情卡：设计与验收

状态：实现与 root 技术验收完成，待用户体验验收；通过前不合入 main。沿用 feat/dynamic-bookshelf，修改基线为 12bc811。本需求替代上一版侧栏/封面飞行的视觉方案，数据和缓存协议保持兼容。结果见 [验收记录](centered-detail-acceptance.md)。

## 用户感受

点击一本书，中央浮起一张暖白详情卡，书架留在下面。动效安静、短促，不产生进入另一个页面的感觉。封面与文字属于同一张卡片，同步出现；关闭后继续浏览原来的书架。

## 布局

- 桌面：卡片水平垂直居中，目标宽 840–860px，四周至少 32px 空隙；暖白底、约 20px 圆角、细边框和柔和阴影。左侧约 190–210px 的封面，右侧书名、作者、简介、推荐值、进度和笔记。保持内容自然密度，不撑满全高。
- 窄屏：仍然居中，左右至少 16px、上下至少 20px。单栏，上部封面与标题紧凑排列，下面为详情。不是底部抽屉。小高度屏幕也不溢出视口。
- 卡片最大高度受 100dvh 限制。长简介在卡片内部滚动，背景页不滚动；关闭按钮始终可见、可点击。短内容不出现多余大块空白。长书名、无封面、有声书、文章入口均能显示。
- 遮罩以约 24% 的暗色为起点，保留可辨认的书架。无背景缩放、模糊、弹跳、旋转和翻页。

## 动效与状态

- 打开：整张卡片 opacity 0→1，scale .97→1，translateY 8px→0，约 240ms，柔和减速；遮罩同期开启、略快。封面不复制、不跨屏移动，文字不逐段延迟。
- 关闭：卡片轻微退回约 .985 / 4px，并淡出，约 160ms；遮罩一起淡出。结束才调用 dialog.close()、释放滚动锁并恢复焦点和原滚动位置。
- 移除旧 ghost/FLIP、飞回封面、侧栏滑入、手机底部滑入及不再使用的状态/关键帧，不叠加两套动画。
- 网络数据不是动画的前置条件：点击即用条目与缓存显示，缺失分区再填充。异步内容更新不能重播整张卡片动画。
- 同一详情中重试或更新内容只更新内容，不重新弹出。动画进行中再次关闭不累积动画；关闭中重新打开取消旧关闭，不允许旧完成回调关掉新详情。
- 支持 prefers-reduced-motion：仅短淡入淡出（约 80ms 或立即完成），不缩放/位移。没有 Web Animations API 时仍能正常开闭。
- 保留原生 dialog、遮罩/按钮/Esc 关闭、焦点约束、原容器原卡片焦点恢复和滚动保持。同步替换原节点、原书移出、异步切书时不出错。
