# 阅读之间 · WeRead Dashboard

一个本地优先的微信读书阅读习惯仪表盘。看看零散阅读如何在每周、每月慢慢积累。

**无需 AI、无需模型 API、无需第三方 Python 或前端依赖。** Python 标准库负责获取数据与本地缓存，原生 JavaScript 和 SVG 负责交互与图表。

## 能看到什么

- 每周阅读与收听时长趋势，以及每周有效阅读天数（悬停查看）。
- 每日阅读热力图，点击日期查看具体时长。
- 累计时长、有效阅读天数、自然日均与有效日均。
- 单月逐日累计曲线，以及当月主要阅读内容。
- 本月、近 3 / 6 / 12 个月切换，以及当前范围的 JSON 导出。
- 手动刷新、最后同步时间、空状态与失败提示。

这里没有小时热力图、连续打卡目标、综合阅读评分或 AI 推荐。项目关注碎片阅读的持续性与积累，不将时长等同于理解程度。

## 快速开始

需要 **Python 3.11+**（包含标准库 `sqlite3`）以及现代浏览器。运行不需要 Node.js、npm 或 pip 安装。

```sh
git clone https://github.com/apue/weread-dashboard.git
cd weread-dashboard
python3 dashboard.py --demo
```

打开 **http://127.0.0.1:8765** 即可查看演示。演示记录由程序生成，明确标识为虚构数据；演示模式不会读取 API key 或真实缓存，也不会调用微信读书。

### 连接自己的微信读书

你需要具有相应权限的微信读书 Agent API key（`wrk-` 开头）。可从微信读书官方提供的 Agent / Skills 接入流程获取；本项目不签发密钥、不处理登录 Cookie，也不保证所有账号都已开放接入。

```sh
cp .env.example .env
chmod 600 .env  # macOS / Linux
```

用文本编辑器填写 `.env`：

```dotenv
WEREAD_API_KEY=你的微信读书API密钥
```

停止演示服务（Ctrl+C），再运行：

```sh
python3 dashboard.py
```

打开页面，点击 **同步数据**。首次同步查询最近 12 个自然月（包含当月）；后续打开页面直接使用本地缓存，没有后台自动刷新。每次手动同步重新查询这 12 个月，以反映上游历史修正。

也可以先同步再启动服务：

```sh
python3 dashboard.py --sync
python3 dashboard.py
```

如果端口被占用，用 `python3 dashboard.py --port 8877`。支持 `WEREAD_API_KEY` 环境变量；非空 `.env` 配置优先。更新密钥后下次同步即生效；切换账号时请先成功同步再查看，旧缓存会一直保留到替换成功。

原有 `python3 test_connection.py` 仍可用来测试只读搜索接口。

## 数据口径

| 项目 | 定义与限制 |
| --- | --- |
| 来源 | `POST https://i.weread.qq.com/api/agent/gateway`，`api_name=/readdata/detail`，`mode=monthly`，skill 版本 `1.0.5` |
| 时区与单位 | 日期按 Asia/Shanghai（UTC+8）；接口原始时长单位为秒 |
| 总时长 | 累加选中月份的 `totalReadTime`，**包含阅读与收听** |
| 有效阅读天数 | 累加 `readDays`；微信读书当前口径为单日满 60 秒 |
| 自然日均 | 总时长 ÷ 观察范围内已过去的自然日数，包含未阅读日 |
| 有效日均 | 总时长 ÷ 有效阅读天数；这是派生值，分子仍含不足一分钟的阅读，不是平均单次时长 |
| 周趋势 | 将月接口 `readTimes` 按周一分组；边界周、当前周和明细缺失周明确标识为不完整 |
| 日历与月累计 | 来自 `readTimes`。缺失日期保留为 `null`，不会补零；未来日期不计入统计 |
| 一致性 | 总量保留接口返回值。日明细缺失或其合计与总量不一致时显示提示；缺失明细月份不画累计曲线 |
| 时间范围 | “近 N 个月”从首月 1 日开始，包含当月；截至快照同步日，而非滚动 N × 30 天 |
| 书目排行 | 每月 `readLongest` 最多返回 10 项，可能过滤低于 5 分钟内容；页面展示前 5 项，不作为完整书籍时间占比 |

只使用已返回数据，没有自动推断阅读场次、专注程度或历史书架状态。上游接口可能调整字段、权限或限流；收到 `upgrade_info` 时停止同步，保留旧数据，需维护者更新官方 skill 并核对版本与字段。

## 隐私与本地运行

- 密钥只在本地后端读取，仅发往固定的微信读书 HTTPS 网关；禁止跟随重定向。
- 页面只接收绘图所需字段，不接收密钥、用户身份字段、完整原始书籍介绍等。
- `.env` 与 `.local/` 已被 Git 忽略。缓存位于 `.local/reading.sqlite3`；在支持 POSIX 权限的平台上，目录限制为 `700`，数据库为 `600`。
- SQLite 为本地明文缓存，不是加密保险库。不要提交数据库、真实导出文件或个人截图。
- 演示模式与真实缓存隔离。公开仓库只含代码、文档和虚构数据生成逻辑。
- 服务仅监听 `127.0.0.1`，校验 Host / Origin / Fetch Metadata，且只允许白名单静态资源。没有账号登录系统，**不适合直接映射到公网或多用户部署**。
- 没有遥测、广告、远程字体、第三方脚本或 CDN 请求。同步时才访问微信读书。
- JSON 导出包含所选范围的个人记录与来源元数据，可用于后续分析；请自己保管。

## 开发与验证

```sh
python3 -m unittest discover -s tests -v
# 可选，需要 Node.js；仅做前端语法检查
node --check web/app.js
node tests/frontend.cjs
```

测试涵盖跨月/闰年日期、未来日期与缺失明细、权威总量、响应校验、演示隔离、敏感路径拒绝、跨站请求拒绝、升级中断与失败缓存保留。CI 在 Python 3.11 / 3.13 上运行离线测试，无需密钥。

```text
dashboard.py          网关客户端、数据归一化、SQLite、HTTP 服务
web/                  中文 dashboard：原生 JS / CSS / SVG
tests/                离线单元与 HTTP 集成测试
.env.example          空白密钥模板
.local/               私有缓存（忽略，不入库）
test_connection.py    只读搜索连通性测试
```

改进建议与贡献见 [CONTRIBUTING.md](CONTRIBUTING.md)。第一版范围保持本地单用户、手动同步、最近 12 个月；更长历史、自定义日期、自动刷新和更多导出格式可继续讨论。
