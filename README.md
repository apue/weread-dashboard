# 阅读之间 · WeRead Dashboard

一个本地优先的微信读书书架与阅读习惯仪表盘。浏览自己的书，看看零散阅读如何在每周、每月慢慢积累。

**无需 AI、无需模型 API、无需第三方 Python 或前端依赖。** Python 标准库负责获取数据与本地缓存，原生 JavaScript 和 SVG 负责交互与图表。

## 能看到什么

- 动态书架、继续阅读、封面和书籍详情；本地搜索、排序及组合筛选。
- 打开书架先显示缓存，再自动同步；也可手动同步，排序与筛选不查询微信读书。
- 封面按需保存到本地，详情与进度分别缓存；桌面与手机均使用居中浮现的详情卡片。
- 每周阅读与收听时长趋势，以及每周有效阅读天数（悬停查看）。
- 每日阅读热力图，点击日期查看具体时长。
- 累计时长、有效阅读天数、自然日均与有效日均。
- 单月逐日累计曲线，以及当月主要阅读内容。
- 本月、近 3 / 6 / 12 个月切换，以及当前范围的 JSON 导出。
- 手动刷新、最后同步时间、空状态与失败提示。

这里没有小时热力图、连续打卡目标、综合阅读评分或 AI 推荐。项目关注碎片阅读的持续性与积累，不将时长等同于理解程度。

## 快速开始

需要 **Python 3.11+**（包含标准库 `sqlite3`）以及现代浏览器。运行不需要 Node.js、npm 或 pip 安装。

```sh
git clone https://github.com/apue/weread-dashboard.git
cd weread-dashboard
python3 dashboard.py --demo
```

打开 **http://127.0.0.1:8765** 即可查看演示。演示记录由程序生成，明确标识为虚构数据；演示模式不会读取 API key 或真实缓存，也不会调用微信读书。

### 连接自己的微信读书

你需要具有相应权限的微信读书 Agent API key（`wrk-` 开头）。可从微信读书官方提供的 Agent / Skills 接入流程获取；本项目不签发密钥、不处理登录 Cookie，也不保证所有账号都已开放接入。

```sh
cp .env.example .env
chmod 600 .env  # macOS / Linux
```

用文本编辑器填写 `.env`：

```dotenv
WEREAD_API_KEY=你的微信读书API密钥
```

停止演示服务（Ctrl+C），再运行：

```sh
python3 dashboard.py
```

打开页面默认进入书架：先显示已有缓存，再后台同步一次书架列表。切换到“阅读统计”查看原有 dashboard；统计数据使用独立的 **同步数据** 按钮。首次统计同步查询最近 12 个自然月（包含当月），以后手动统计同步仍重新查询这 12 个月，以反映上游历史修正。切换页面、搜索、排序及筛选不会触发书架同步或重拉统计。

也可以先同步阅读统计再启动服务（`--sync` 不同步书架）：

```sh
python3 dashboard.py --sync
python3 dashboard.py
```

如果端口被占用，用 `python3 dashboard.py --port 8877`。支持 `WEREAD_API_KEY` 环境变量；非空 `.env` 配置优先。更新密钥后下次同步即生效；切换账号时请先成功同步再查看，旧缓存会一直保留到替换成功。

原有 `python3 test_connection.py` 仍可用来测试只读搜索接口。

## 书架与本地缓存

书架来自 `/shelf/sync`，条目数包含电子书、有声书和非空的文章收藏入口。内容完结不等于用户听完；没有进度记录时显示未知。搜索匹配书名、作者，支持最近阅读／书名／作者排序，以及分类、类型和已读完筛选。浏览偏好只保存到浏览器 `localStorage`，禁用该存储不影响使用。

书架快照、书籍详情、进度与笔记概览分别保存成功时间。详情与进度按需读取；每次书架同步只补最近最多 4 本电子书的进度，避免逐本查询全架。笔记概览通过详情中的独立按钮同步，总笔记数为划线、想法和书签数之和。尚未同步不显示为零。

封面 URL 由微信读书返回，后端按需下载并缓存在 `.local/covers/`，浏览器只访问本地图片。已缓存封面可离线显示，下载失败显示占位；封面 URL 改变后使用新缓存。图片下载只允许指定的微信读书 HTTPS 图片来源，不提供任意 URL 代理。

书架缓存按当前密钥在后端隔离；更换密钥后需要重新同步，不显示原密钥对应的书架。接口失败保留上次成功数据；合法的空书架会更新为空。缓存是本地明文文件。该功能仅查看自己的授权数据，不添加、删除或回写微信读书书架。

点击封面可展开详情；卡片尺寸由视口决定，加载和刷新内容时保持外框位置稳定，长内容在内部滚动。同一会话再次打开已读过的详情会先显示内存缓存，成功同步书架后清空该缓存。支持关闭按钮、遮罩和 Esc，关闭后返回原浏览位置。系统启用“减少动态效果”时简化动画。“继续阅读”只使用接口实际返回的跳转链接。

详情推荐值按上游 `newRating ÷ 10` 展示为百分数，已与官方书籍详情页核对。单书累计时长的字段口径尚未确认，暂不展示；阅读统计页仍使用原有的权威总量。

## 数据口径

| 项目 | 定义与限制 |
| --- | --- |
| 来源 | `POST https://i.weread.qq.com/api/agent/gateway`，`api_name=/readdata/detail`，`mode=monthly`，skill 版本 `1.0.5` |
| 时区与单位 | 日期按 Asia/Shanghai（UTC+8）；接口原始时长单位为秒 |
| 总时长 | 累加选中月份的 `totalReadTime`，**包含阅读与收听** |
| 有效阅读天数 | 累加 `readDays`；微信读书当前口径为单日满 60 秒 |
| 自然日均 | 总时长 ÷ 观察范围内已过去的自然日数，包含未阅读日 |
| 有效日均 | 总时长 ÷ 有效阅读天数；这是派生值，分子仍含不足一分钟的阅读，不是平均单次时长 |
| 周趋势 | 将月接口 `readTimes` 按周一分组；边界周、当前周和明细缺失周明确标识为不完整 |
| 日历与月累计 | 来自 `readTimes`。缺失日期保留为 `null`，不会补零；未来日期不计入统计 |
| 一致性 | 总量保留接口返回值。日明细缺失或其合计与总量不一致时显示提示；缺失明细月份不画累计曲线 |
| 时间范围 | “近 N 个月”从首月 1 日开始，包含当月；截至快照同步日，而非滚动 N × 30 天 |
| 书目排行 | 每月 `readLongest` 最多返回 10 项，可能过滤低于 5 分钟内容；页面展示前 5 项，不作为完整书籍时间占比 |

只使用已返回数据，没有自动推断阅读场次、专注程度或历史书架状态。上游接口可能调整字段、权限或限流；收到 `upgrade_info` 时停止同步，保留旧数据，需维护者更新官方 skill 并核对版本与字段。

## 隐私与本地运行

- 密钥只在本地后端读取，仅发往固定的微信读书 HTTPS 网关；禁止跟随重定向。
- 页面只接收统计与书架展示所需字段及按需读取的简介，不接收密钥、用户身份字段或完整原始回包。
- `.env` 与 `.local/` 已被 Git 忽略。缓存位于 `.local/reading.sqlite3`；在支持 POSIX 权限的平台上，目录限制为 `700`，数据库为 `600`。
- SQLite 为本地明文缓存，不是加密保险库。不要提交数据库、真实导出文件或个人截图。
- 演示模式与真实缓存隔离。公开仓库只含代码、文档和虚构数据生成逻辑。
- 服务仅监听 `127.0.0.1`，校验 Host / Origin / Fetch Metadata，且只允许白名单静态资源。没有账号登录系统，**不适合直接映射到公网或多用户部署**。
- 没有遥测、广告、远程字体或第三方脚本。同步或按需加载详情、封面时由后端访问微信读书，浏览器只访问本地服务。
- JSON 导出包含所选范围的个人记录与来源元数据，可用于后续分析；请自己保管。

## 开发与验证

```sh
python3 -m unittest discover -s tests -v
# 前端检查需要 Node.js；运行应用不需要
node --check web/app.js
node --check web/shelf.js
node tests/frontend.cjs
node tests/shelf_frontend.cjs
node tests/detail_motion.cjs
```

视觉回归可运行 `python3 tests/detail_visual_server.py --port 8777 --get-delay-ms 300 --sync-delay-ms 1500 --long-intro --long-title`，打开输出地址后点书，检查加载各阶段是否稳定。该工具仅使用虚构演示数据；延迟、慢放及逐帧探针不会进入正常应用，使用方法与结果见 [详情稳定性验收](docs/detail-stability-acceptance.md)。开闭浮层的背景横向位移已另行修复，复现方法与逐帧证据见 [页面滚动条修复验收](docs/viewport-scrollbar-fix.md)。

测试涵盖跨月/闰年日期、未来日期与缺失明细、权威总量、响应校验、演示隔离、敏感路径拒绝、跨站请求拒绝、升级中断与失败缓存保留。CI 在 Python 3.11 / 3.13 上运行离线测试，无需密钥。

```text
dashboard.py          阅读统计、HTTP 服务与路由
bookshelf.py          书架网关、数据归一化、独立缓存与封面下载
web/                  中文 dashboard：原生 JS / CSS / SVG
tests/                离线单元与 HTTP 集成测试
.env.example          空白密钥模板
.local/               私有缓存（忽略，不入库）
test_connection.py    只读搜索连通性测试
```

改进建议与贡献见 [CONTRIBUTING.md](CONTRIBUTING.md)。范围保持本地单用户；阅读统计查询最近 12 个月，书架打开时自动同步。更长统计历史、自定义日期和更多导出格式可继续讨论。动态书架的完整需求和验收约定见 [设计文档](docs/dynamic-bookshelf.md)，当前详情布局见 [加载稳定性设计与验收](docs/detail-stability.md)。
